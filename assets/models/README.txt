3D MODEL ASSETS
================
The supplied project report contains screenshots of the digital-twin interface, but the actual GLB model files were not included in the uploaded source files.

To activate the interactive viewer on the main page, place a GLB file here with this exact filename:

handloom-01.glb

The viewer is implemented with <model-viewer> and will support mouse/touch orbit, zoom and auto-rotation. Additional model files can be wired into the interface later without changing the page structure.
