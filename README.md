# Empowering Handloom Artistry — Digitalising Heritage

GitHub Pages-ready digital research archive for the BC–CTC–2024 project **Empowering Handloom Artistry: A Digital Approach to Globalize the Heritage Handloom Industry in Sri Lanka**.

## Focus
- Sri Lankan handloom heritage and fieldwork
- Contemporary fashion translation
- Digitalisation and 3D digital twins
- UK–Sri Lanka research exchange
- Short perceptual study module

## 3D viewer
The interactive viewer is **lazy-loaded**. The page does not load the model-viewer library or the project GLB at startup. Visitors click **Load 3D twin** to begin the download.

The model is stored at:

`assets/models/handloom-01.glb`

## Deploy
Upload the contents of this folder to a GitHub repository and enable **Settings → Pages → Deploy from branch**.

The site is static and does not require a backend.
