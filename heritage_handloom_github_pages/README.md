# Empowering Handloom Artistry — GitHub Pages site

Static HTML/CSS/JS website for the research project **Empowering Handloom Artistry: A Digital Approach to Globalize the Heritage Handloom Industry in Sri Lanka**.

## Deploy

1. Upload the contents of this folder to a GitHub repository.
2. In GitHub: **Settings → Pages → Deploy from a branch**.
3. Select the `main` branch and `/ (root)`.
4. Save. GitHub Pages will publish `index.html`.

No build step is required.

## Included

- Single-page research archive with sections for handlooms, collection, digital twins, fieldwork, exchange and research.
- Responsive navigation and province filter for 15 fieldwork centres.
- Visuals extracted from the supplied project-report PDF and compressed for web use.
- 3D digital-twin viewer shell using `<model-viewer>`.
- A separate `study/` information module for the perceptual-study child project.

## 3D models

The uploaded report contains screenshots of the 3D/digital-twin system but did not include the actual GLB model files. Put a project model at `assets/models/handloom-01.glb` to activate the viewer. See `assets/models/README.txt`.

## Visual source

Images in `assets/images/` were extracted from the supplied project report PDF. The site uses them as documentary/project imagery rather than claiming they are original source files from the field.

## Content note
